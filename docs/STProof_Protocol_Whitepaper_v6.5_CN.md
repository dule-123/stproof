# STProof 协议白皮书
## 版本：v6.5 | 2026
## 数字文明事实层

> 不确权物，只确权事

---

# 摘要
STProof 是一个去中心化的**事件型链上存证协议**。
它通过多源证据、可信时间戳、IPFS 存储和验证者背书，对**真实发生的客观事件**进行链上确权。

v6.5 版本**彻底重构经济模型**，移除不可落地的引用税，采用**可持续、合规、可运营**的收藏经济模型，并支持限量版事件 NFT、动态证据、策展模块（Storyline）和邮戳式收藏玩法。

协议现已支持**事件收藏游戏**，让生态实现自我造血、用户自驱动。

---

# 1. 引言
数字时代面临信任崩塌：伪造、深度伪造、信息操纵让事实失去可信度。

区块链提供不可篡改能力，但大多数方案只能证明**文件存在**，无法证明**事件真实发生**。

STProof 的创新：
- 只证明发生过什么
- 何时发生
- 谁参与
- 有什么证据
- 不绑定实物所有权、无金融风险

STProof v6.5 专为**真实落地、真实用户、真实可持续**而设计。

---

# 2. 核心理念
STProof **只做一件事：事件确权**。

它证明：
- 事件真实发生
- 证据真实有效
- 验证者背书可信
- 历史可追溯

它不证明：
- 实物所有权
- 资产价值
- 产权或法律权属
- 投资收益或金融承诺

---

# 3. 事件 NFT 模型（ERC-721）
每个事件铸造为一枚**事件 NFT**。

NFT 代表：
- 事件本身
- 证据链
- 验证状态
- 限量版号
- 收藏资格

它不代表：
- 实物
- 金融资产
- 实体资产映射（RWA）
- 投资合约

---

# 4. 协议架构
1. **事件层** – 事件模板与标准
2. **证据层** – IPFS + 可信时间戳 + 版本历史
3. **验证层** – 无需许可验证者 + 多签背书
4. **NFT 层** – ERC-721 限量版资产
5. **经济层** – 可持续收藏经济
6. **策展层** – 合集、故事线、叙事
7. **安全层** – 重入防护、权限控制、审计友好

---

# 5. 经济模型（v6.5 可持续、可落地）
STProof v6.5 **完全移除引用税**，因其不具备现实可行性。

新版模型基于**收藏驱动 + 服务收费**，合规、简单、可长期运行。

## 5.1 收入来源
1. **限量版铸造费**
   官方系列、邮戳式藏品、主题套系。

2. **验证服务费用**
   验证者背书、官方核验。

3. **二级市场 5% 版税**
   兼容 EIP-2981。

4. **机构与企业 API 服务**
   媒体、法律、学术、文博机构订阅服务。

## 5.2 收益分配
- **70% 事件创建者**
- **28% 生态金库**
- **2% 协议开发与维护**

## 5.3 模型优势
- 无不可落地的引用税
- 收藏模式合规安全
- 真实需求驱动、长期稳定
- 收藏玩法带来自然增长
- 零金融化、零证券化风险

# 6. v6.5 核心功能

## 6.1 限量版事件 NFT
- 固定版次（如 1/100、1/500）
- CID 防重复铸造
- 邮戳卡/明信片式收藏支持
- 适合系列化发行

## 6.2 动态证据系统
- 随时追加新证据
- 全链上版本历史
- IPFS 不可篡改存储
- 法律、审计友好

## 6.3 验证者背书系统
- 无需许可自由加入
- 多签验证机制（≥2 人验证即生效）
- 链上证言 + 评论 CID

## 6.4 Storyline 策展模块
- 创建公开/私人收藏册
- 将事件组成系列、故事、专题
- 点赞与社区治理
- 事件收藏游戏的核心载体

## 6.5 安全全面加固
- 重入攻击防护
- 零地址校验
- 安全转账
- 手动收益提现（合规优先）

## 6.6 标准兼容
- ERC-721
- EIP-2981 版税
- ERC-165 接口检测
