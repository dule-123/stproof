# STProof Protocol Whitepaper
## Version: v6.5 | 2026
## Fact Layer of Digital Civilization

> Not Proof of Asset. Only Proof of Event.

---

# Abstract
STProof is a decentralized event-based on-chain proof protocol.
It certifies **objectively occurred events** with multi-source evidence, trusted timestamps, IPFS storage, and validator attestations.

Version 6.5 rebuilds the economic model to be **sustainable, compliant, and realistic**, removing unfeasible citation fees and introducing a collectible stamp-style economy, limited-edition event NFTs, dynamic evidence, and a curation system (Storyline).

The protocol now supports **Event Collection Gameplay**, similar to stamp or postcard collecting, making the ecosystem self-sustaining and user-driven.

---

# 1. Introduction
The digital age suffers from trust collapse: forgery, deepfake, and manipulation make facts untrustworthy.

Blockchain provides immutability, but most solutions only certify files, not **real events**.

STProof changes this:
- It certifies what happened
- When it happened
- Who participated
- What evidence supports it
- Without binding physical ownership or financial risks

STProof v6.5 is designed for **real adoption, real users, and real sustainability**.

---

# 2. Core Concept
STProof focuses **only on event certification**.

It proves:
- Occurrence of an event
- Authenticity of evidence
- Validity via validator attestation
- Historical traceability

It does NOT certify:
- Ownership of physical assets
- Value of assets
- Legal title or property rights
- Investment or financial returns

---

# 3. Event NFT Model (ERC-721)
Each event is minted as an **Event NFT**.

The NFT represents:
- The event itself
- Evidence chain
- Verification status
- Edition number (limited editions)
- Collection eligibility

It does NOT represent:
- Physical objects
- Financial assets
- RWAs
- Investment contracts

---

# 4. Protocol Architecture
1. **Event Layer** – Event templates and standards
2. **Evidence Layer** – IPFS + trusted timestamp + version history
3. **Validation Layer** – Permissionless validator + multi-sign attestation
4. **NFT Layer** – ERC-721 limited-edition assets
5. **Economic Layer** – Sustainable collectible economy
6. **Storyline Layer** – Curation, collection, and narratives
7. **Security Layer** – Reentrancy guard, access control, audit-ready

---

# 5. Economic Model (v6.5 – Sustainable & Realistic)
STProof v6.5 **removes citation fees** entirely, as they are not operationally feasible.

The new model is **collectible-driven, service-based, and compliant**.

## 5.1 Revenue Sources
1. **Limited-Edition Minting Fees**
   Official series, stamp-style collectibles, thematic sets.

2. **Verified Event Services**
   Validation by trusted attestors.

3. **Secondary Market Royalties (5%)**
   EIP-2981 compliant.

4. **Institutional & Enterprise API Services**
   For media, legal, academic, and museum clients.

## 5.2 Revenue Distribution
- **70% Event Creator**
- **28% Treasury**
- **2% Protocol Development & Maintenance**

## 5.3 Advantages
- No unfeasible citation fees
- Compliant collectible model
- Stable, real-demand revenue
- User-driven growth via collection gameplay
- Zero financial or security risks
