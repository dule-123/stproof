## 摘要
STProof（Spatial-Temporal Proof）是一套面向**客观历史事件**的通用链上确权与价值捕获协议。它通过多源证据交叉验证、可信时间戳、去中心化存储与链上锚定，将真实发生的事件转化为数字世界不可篡改的永久记录。

协议的确权对象统一为**事件本身**，不确权任何实体资产、不映射任何实物权益，彻底规避 RWA 风险。有实物的事件（如实寄封、艺术品创作），实物仅为事件发生的现场载体；无实物的事件（如线上发布、链上投票、协议诞生），协议直接对数字行为进行存证与确权。

协议以**零知识思想确权**为底层方法论：在不泄露敏感信息、不暴露原图/原物IP、不展示私密内容的前提下，仅依靠公开权威事实与多源交叉验证，即可证明事件真实发生，并将其铸造为可独立流通的数字原生凭证。

经济模型坚持**平权优先**：任何人只需支付 Gas 费即可铸造 Event NFT，无额外门槛。事件价值来自**被引用、被使用、被信任**的广度，而非二级市场炒作。每一次链上引用，都是对真实的一次投票。

为保障协议长期迭代、技术维护与生态安全，**协议缔造者享有 2% 永久、透明、链上可验证权益**，全部收益来自协议生态产生的引用费、访问费与激励费，不稀释事件发起人核心收益。

协议首个落地案例从实物场景升级为**STProof 自指实验（元事件）**，证明协议可完全脱离物理世界独立运行，成为数字文明的事实基础设施。

# 1 引言：物理世界事实的记录难题
人类文明依赖对“事实”的记录。从石刻、羊皮卷到数字档案，我们一直在寻找更可靠的方式保存历史。然而，在信息爆炸与 AI 伪造技术并行的今天，事实的“真实性”正面临前所未有的挑战。

- 传统记录方式依赖中心化机构（公证处、档案馆、鉴定专家），但存在成本高、易篡改、跨国验证难等问题。
- 区块链与 NFT 提供了去中心化、不可篡改的载体，但绝大多数 NFT 仅锚定“数字文件”，缺乏与物理世界事实的刚性连接。
- 预言机可将链下数据（如价格、天气）喂入链上，但只能处理可 API 化的标准化数据，无法应对独一无二、需要人类判断的非标事件。

一枚邮票是否真的在首日被实寄？一幅画是否真的出自某位画家之手？一件文物是否真的出土于某处遗址？一篇文章是否真的在某个时间首次发布？
这些问题无法通过 API 回答，却恰恰构成了人类历史与数字文明的重要部分。

STProof 协议的诞生，正是为了填补这一空白。

# 2 STProof：事件确权协议

## 2.1 定义
STProof 是一套面向“事件”的通用链上确权与价值捕获协议。协议的确权对象统一为客观发生的历史事件，而非任何实体资产或数字内容本身，从而实现全场景、跨形态的一致可信机制。

三类事件均纳入协议范围：
- **有实物事件**：实物作为事件发生的现场载体，如实寄封邮寄、书画创作、瓷器烧制、文物出土。
- **无实物事件**：纯数字或行为事件，无伴随实物，如线上发布、链上投票、观点声明、学术发表。
- **混合事件**：有实物但实物非核心，或实物与数字并存，如新闻现场、演出、法律存证。

核心理念：
实物归实物世界，事件归区块链世界。
NFT 只锁事件，不锁物品。从此彻底无 RWA。

事实的记录不应有资金门槛。无论贫富，每个人都有权为自己经历的真实事件建立永久的链上凭证。

事件的价值来自于被使用。引用税机制让价值与影响力挂钩，而非与炒作挂钩。

## 2.2 核心要素
每个事件确权包含五个核心要素：

1. **时间**：事件发生的真实时间。
2. **空间**：事件发生的真实地点或链上坐标。
3. **主体**：事件的参与者。
4. **事实**：事件的具体内容。
5. **证据**：支撑事实的多源材料。

## 2.3 事件模板：协议的可扩展基础
协议不预设所有事件的证据规则。相反，协议提供模板层——社区可以为不同事件类型定义验证标准。

模板包含：
- 证据要求（需要哪些维度的证据）
- 验证者画像（谁有资格验证该类事件）
- 引用场景（谁会引用、为什么引用）
- 可选模块（是否启用实物存留、物理验证等）

模板的治理：
- 任何社区成员可提案创建新模板
- 模板需经验证者网络或 DAO 投票通过
- 模板创建者可获得模板使用费分成

这种设计使协议具备无限扩展性。首日封曾是“有实物事件模板”的第一个案例，而 STProof 自指实验则成为数字原生事件的创世模板。

## 2.4 证据采集与验证标准
无论事件类型如何，协议遵循以下通用原则：

- **多源独立性**：证据应来自至少两个独立来源。独立来源越多，证据强度越高。
- **交叉验证**：不同来源的证据应包含共同的唯一标识符，形成闭环。
- **可信时间戳**：证据包需通过国家认可的时间戳机构固化，证明其在特定时间点之前已存在。
- **去中心化存储**：证据包上传至 IPFS/Arweave，获取内容寻址 CID，确保内容不可篡改。
- **分层披露**：证据可分“公开包”与“私有包”，公开包用于市场展示，私有包用于定向验证。

具体证据规则由事件模板定义。

## 2.5 实物存留机制（可选模块）
适用对象：仅适用于伴随实物的事件类型。对于无实物事件，此模块不适用。

对于有实物事件，实物作为事件发生的原始物证，其存留方式由发起人自行决定：
- **销毁实物**：使 NFT 成为事件的唯一链上代表，彻底数字化。
- **保留实物**：保留物理原件，作为“终极仲裁”的证据。可选择将实物托管于可信第三方。

需要明确的是：物理实物的存留仅作为事件真实性的历史见证，不代表任何资产所有权或收益权，不与 NFT 形成权属绑定、价值映射或资产抵押关系。协议始终坚持“事件归区块链世界，实物归实物世界”的原则。

## 2.6 铸造与审查：开放与秩序的平衡
协议坚持“任何人只需支付 Gas 费即可铸造”的平权原则。但同时，为确保上链事件的真实性和合法性，协议通过社区治理引入软性审查机制：

- **铸造后验证**：事件铸造后需经过验证者网络验证。验证不通过的事件将被标记为“存疑”，影响其信誉和可引用性。
- **内容争议仲裁**：任何社区成员均可对事件内容提出质疑，由社区验证者或 DAO 进行仲裁。
- **模板引导**：通过“事件模板”引导用户记录有公共价值的事件，而非鼓励随意记录私密琐事。

这种“开放铸造 + 事后验证 + 声誉约束”的模式，在开放与秩序之间取得平衡。

## 2.7 核心方法论：零知识思想确权
STProof 的底层方法论是**零知识思想确权**，它不等同于密码学零知识证明，而是一套基于社会共识、逻辑推理与多源验证的实用确权体系。

三大原则：
1. **完整性**：真实事件一定能构造出可验证的证据链。
2. **可靠性**：虚假事件无法通过证据链验证。
3. **零知识性**：验证者仅获得“事件为真”的结论，无法接触敏感信息、原图 IP、商业机密或隐私内容。

这一方法论是 STProof“不确权物、只确权事”的理论根基，也是协议在数字藏品、知识产权、跨境协作等场景实现合规确权的核心支撑。

# 3 实物与 NFT 的关系：事件确权模型
STProof 的确权对象统一为客观发生的历史事件，而非任何实体资产或数字内容本身。对于伴随实物的事件，实物仅为事件发生的现场载体，不与链上凭证形成权属绑定、价值映射或资产抵押关系；对于无实物的纯数字/行为事件，协议直接对事件本身进行存证、确权与激励。

**实物归实物世界，事件归区块链世界。**
**NFT 只锁事件，不锁物品。**

STProof 协议的核心创新，在于重新定义了实物与数字凭证的关系。它摒弃了传统的“实物映射”思维，转向“事件确权”范式。

协议采用事件确权模型（Event-Based Provenance），链上 NFT 不代表任何实物资产，不构成实物的所有权、使用权、处置权或收益权凭证，也不与实物形成 RWA（真实世界资产）映射关系。

NFT 唯一确权与记录的对象，是实物诞生与流转过程中的关键历史事件，包括但不限于：
- 创作/制作事件：创作、制作、烧制、落款
- 发行/流通事件：发行、邮寄、原地
- 完成/终结事件：完成、出土、修复、销毁

实物作为事件发生的现场载体，保持其独立的物权、商业价值与收藏属性，与链上 NFT 不存在隶属、绑定、质押、抵押或价值托底关系。

两者仅在历史事实上发生关联，在权属、资产、金融属性上完全分离、相互独立。

由此，STProof NFT 成为纯粹的事件凭证，而非资产凭证，从底层结构上彻底避免双重权属、重复确权与 RWA 监管风险。

对于无实物的事件，上述原则同样适用——只是“现场载体”不存在，NFT 直接锚定事件本身，更加纯粹。

# 4 协议架构
STProof 由以下层次构成：

1. **事件模板层**：定义不同事件类型的验证规则，由社区提案、智能合约模板实现。
2. **验证者网络层**：对事件真实性进行多签验证，由机构验证者 + 社区验证者组成。
3. **证据存储层**：存储多源证据材料，基于 IPFS/Arweave + 可信时间戳。
4. **NFT 资产层**：将事件锚定为链上资产，采用 ERC-721 动态 NFT，支持元数据更新。
5. **经济模型层**：分配验证费、版税、引用费、访问费，由智能合约自动分配 ETH/USDC。

# 5 经济模型：平权优先的激励机制
STProof 坚持一个核心理念：事实的记录不应有资金门槛。无论贫富，每个人都有权为自己经历的真实事件建立永久的链上凭证。技术不应该制造新的不平等。

传统 NFT 的价值发现依赖二级市场的转售价格，这本质上是“投机逻辑”——等待下一个愿意出更高价的人。但事件 NFT 的价值，不应来自少数人的炒作，而应来自它在社会中被相信、被引用的广度。

STProof 开创“引用税”机制，让事件的价值回归其本质：被越多的人使用，就越有价值。引用次数成为衡量事件影响力的透明指标，每一次链上引用都是一次对真实性的公开背书，推动优质事件 NFT 实现基于事实的价值发现。

基于这一理念，协议设计了三层并行的价值捕获机制，确保所有人都能平等参与，同时让事实的创作者能够从影响力的扩散中获得持续回报。

## 5.1 角色与收益来源
| 角色 | 贡献 | 收益来源 |
|---|---|---|
| 事件发起人 | 采集证据、铸造 NFT | 版税（转售）、引用费（链上引用）、访问费（付费下载） |
| 验证者（志愿） | 验证事件真实性，签名背书 | 声誉积分、社区认可 |
| 验证者（激励） | 验证事件真实性，签名背书 | 验证费（ETH） |
| 模板创建者 | 设计新事件类型的验证规则 | 模板使用费（ETH） |
| 协议金库 | 用于补贴、审计、社区发展 | 引用费分成（30%）、激励验证费分成（30%） |

## 5.2 铸造与验证机制
任何人只需支付 Gas 费即可铸造 Event NFT，无需支付额外铸造费。协议提供两种验证模式，供发起人根据自身情况选择：

| 模式 | 费用 | 验证速度 | 适用场景 |
|---|---|---|---|
| 社区志愿验证 | 免费 | 较慢 | 个人记忆、家庭记录、非紧急事件 |
| 激励验证 | 发起人自愿支付 | 快速 | 需快速确权的事件、商业用途 |

## 5.3 转售版税（Royalty）
每次 NFT 转售，收取成交价的 5%（符合 EIP-2981 标准），全部归事件发起人所有，以激励事实的原创记录者。

## 5.4 链上引用：事实的价值来自被使用
STProof 认为，事件 NFT 的核心价值不在于被转售，而在于被引用。引用税是体现事件价值的真正武器，是优质事件 NFT 价值发现的核心过程。一枚事件 NFT 被引用得越多，它在社会中的影响力越大，其作为“事实”的权威性越强。

为此，协议引入引用费机制。任何用户或智能合约均可通过调用 `cite` 函数，声明引用某个事件 NFT，并支付一笔小额费用。该费用由智能合约自动分配：
- 70% 分配给事件发起人
- 30% 进入协议金库

每次引用均在链上永久记录，成为事件 NFT 的信誉证明。引用次数越高，说明该事件被越多的人相信和使用，其价值也随之增长。引用记录可被第三方应用直接调用，形成正向循环。

## 5.5 双层机制与付费访问
为了让不熟悉链上操作的用户也能为事实的价值做出贡献，协议设计了双层证据访问机制：

| 层级 | 内容 | 访问方式 | 收费模式 |
|---|---|---|---|
| 公开包 | 缩略图、关键证据摘要、低分辨率影像 | IPFS 公开网关，CID 公开 | 免费 |
| 完整包 | 高清影像、原始收据、完整 GPS 轨迹、时间戳证书 | 通过协议付费网关访问 | 按次/订阅 |

## 5.6 事件价值的多维延伸
引用税是 STProof 捕获事件影响力的核心机制，但事件的价值是多维的。协议未来将逐步引入更多价值维度，让价值发现更加立体：稀缺性与独特性、时效性与历史阶段、证据链强度、社会共鸣度与情感价值、实用性与应用价值、组合价值与叙事链。

核心原则：引用税是持续现金流的基础，其他维度作为价值放大器，影响引用概率和二级市场定价。

## 5.7 三层价值捕获模型总结
| 收入来源 | 触发条件 | 费率/金额 | 分配 |
|---|---|---|---|
| 版税 | NFT 转售 | 成交价 5% | 发起人 100% |
| 链上引用费 | 链上调用 cite | 标准定额 | 发起人 70% + 金库 30% |
| 付费访问费 | 网关下载完整包 | 按次/订阅 | 发起人 70% + 金库 30% |

三者形成互补：
- 版税捕获稀缺性价值
- 引用费捕获影响力价值
- 访问费捕获知识传播价值

## 5.8 协议金库管理
- 收入来源：引用费分成（30%）、激励验证费分成（30%）。
- 初期管理：由 2/3 多签钱包控制，成员包括协议发起人、核心贡献者、社区代表。
- 资金用途：补贴新模板开发、智能合约审计、黑客松活动、社区奖励、补贴 Gas 费。
- 分配流程：社区提案 → 多签投票 → 链上执行，收支公开透明。
