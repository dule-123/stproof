### 1.1 Collect Official Release Bulletin (Source Evidence)

| Item | Description | Key Points |
|------|-------------|------------|
| Source | China Post official website / public account | Screenshot must include **URL bar** |
| Content | Stamp code, name, issue date, denomination | Ensure key fields are captured |
| Screenshot | No cropping or editing | Can record screen while opening the page |
| Storage | Original screenshot + IPFS + OTS | First item of public assets |

**Key fields to capture**:
- [ ] Stamp name (Chinese + English)
- [ ] Stamp code (e.g., 2026-3)
- [ ] Issue date (exact day)
- [ ] Denomination / set quantity
- [ ] Issuer (China Post Group Corporation)
- [ ] Official URL

### 1.2 Define Basic Event Elements

| Element | Description | Example |
|---------|-------------|---------|
| Stamp Theme | From bulletin | Chinese Seal Engraving III |
| Core Date | From bulletin | 2026-04-20 |
| Mailing Date | Actual mailing date | 2026-04-20/21 |
| Core Location | Post office name | Shenzhen Nanyou Post Office |
| Series Number | NFT series number | #001 ~ #009 |
| Handwritten Code | Unique per cover | STP_FDC_20260420_001 |

### 1.3 Create Unique Handwritten Code

- Format: `STP_FDC_YYYYMMDD_XXX`
- Example: `STP_FDC_20260420_001`
- Write clearly on the envelope (front or back) with permanent ink

### 1.4 Field Execution Tool Checklist

**Required Apps**:

| Purpose | Recommended App | Key Points |
|---------|-----------------|------------|
| Screen Recording | Built-in recorder | Record continuously to prove timeline |
| GPS Track | GPX Logger / Strava | Start before departure, export .gpx |
| Weather | China Weather / Weather.com | Screenshot with date + location + temperature |
| Postal Query | China Post App / Cainiao | Record tracking history |
| Camera | Built-in camera | Enable geolocation |

**Pre-departure Checklist**:
- [ ] System time: auto-sync enabled
- [ ] Camera geolocation: enabled
- [ ] Screen recording mic: enabled
- [ ] GPS background location: enabled
- [ ] Storage space: ≥10GB
- [ ] Battery: ≥80%, bring power bank

**Physical Items**:
- [ ] Newspaper of the day (only show header + date)
- [ ] Envelopes with handwritten codes
- [ ] Stamps / envelope set
- [ ] Permanent marker / pen
