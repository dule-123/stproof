# STProof 物理事件确权 SOP

本目录包含从物理事件到链上 NFT 的完整标准操作流程。

## 流程概览

事件设计 → 官方公报采集 → 现场执行 → 资料归集 → 哈希计算 → OTS时间戳 → IPFS上传 → 三层JSON生成 → 铸造NFT

## 核心原则

> **公开文件 = OTS + IPFS**  
> **私密文件 = SHA256 only（不上传）**  
> **公私永远分离，绝不出错**

> **L1 公共公开 = 所有信封共用**  
> **L2 独立公开 = 每封独立**  
> **L3 私密 = 每封独立，不上原图**

> **cid = 文件本身的CID**  
> **timestamp_proof_cid = 对应.ots文件的CID**  
> **不是同一个，不能留空**
