# public_assets Field Specification

Each public asset contains:

{
  "name": "filename.jpg",
  "description": "Description",
  "type": "image/jpeg",
  "cid": "bafyxxx（CID of the file itself）",
  "timestamp_proof_cid": "bafyxxx（CID of the .ots file）"
}
