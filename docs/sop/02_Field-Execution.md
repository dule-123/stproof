### 2.1 Post Office Photography Compliance Rules

**Core Principle**: Do not disrupt work, photograph staff faces, internal procedures, or other customers.

| Prohibited | Risk Level |
|------------|-------------|
| Staff faces up close | 🔴 High |
| Other customers | 🔴 High |
| Computer screens / interfaces | 🔴 High |
| Counter interior / back area | 🟡 Medium |

| Allowed | Safety Tips |
|---------|--------------|
| Post office sign (exterior) | Public area |
| Close-up of your own envelope | Stamps, codes, postmarks allowed |
| Handwritten code + receipt together | Do it in a corner |
| Envelope with postmark | Only envelope, not the stamping process |

### 2.2 "5 Mandatory Photos" Per Cover

| # | Subject | Key Requirement |
|---|---------|-----------------|
| ① | Envelope with stamp | Stamp + handwritten code together |
| ② | Handwritten code close-up | Clear code, block out address |
| ③ | Envelope with commemorative postmark | Postmark + code together |
| ④ | Envelope with date postmark | Date clearly visible, must be issue date |
| ⑤ | Receipt + Envelope + Code together | **Most easily missed, must take** |

### 2.3 Batch Operation Anti-miss Process

Complete each cover independently before moving to the next:

1. Stamp + handwritten code → Photo ①
2. Commemorative postmark → Photo ②
3. Date postmark → Photo ③
4. Counter (weighing, entry, barcode, receipt)
5. **Immediately take Photo ⑤** after receiving receipt
6. Put in safe bag → Next cover

**On-site Quick Checklist**:
- [ ] ① Stamp + code
- [ ] ② Commemorative postmark + code
- [ ] ③ Date postmark + code
- [ ] ④ Counter done
- [ ] ⑤ **Receipt + Envelope + Code** ⭐

### 2.4 Video Recording Design (Segmented)

| Segment | Location | Duration | Content |
|---------|----------|----------|---------|
| ① | Outside post office | 30-60 sec | Envelope → phone time → weather → sign |
| ② | Inside post office | 10-15 sec each | Envelope postmark close-ups, receipt + envelope |
| ③ | Outside / after | 30 sec | Complete envelope + receipt + code |

**Internal Recording Tips**:
- Each segment ≤ 15 seconds
- Only record envelope close-ups, don't pan around
- Prioritize photos for receipt + envelope

**Recording Compliance Check**:
- [ ] Segment ① completed outside
- [ ] Phone in airplane mode + WiFi off
- [ ] Each internal segment < 15 sec
- [ ] Only envelope close-ups
- [ ] Segment ③ completed after leaving
