# Security Policy

## Supported Versions
Only the latest deployed testnet version of STProof Protocol is currently supported.

## Reporting a Vulnerability
We take security vulnerabilities seriously.

For critical security issues, please do NOT disclose them publicly in issues or Discord channels.
Please report them directly via:
- Email: dule07282@gmail.com
- Discord: @stproof_prtocol

We will acknowledge your report within 24 hours and work with you to resolve the issue promptly.
