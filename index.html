协议核心理念

聚焦事件本身，构建无资产绑定、无RWA风险的可信事实层

事件唯一确权

只确权客观发生的事件，不映射实物、不绑定资产所有权，无RWA合规风险。

平权铸造

任何人只需支付Gas费用，即可创建事件NFT，无准入门槛。

零知识思想确权

不泄露隐私和核心数据，即可完成事件真实性验证。OTS时间戳+IPFS双链锚定。

多源证据交叉验证

时间、地点、主体、行为、材料多方交叉验证，确保事件真实可追溯。

手动收益提现

收益存入合约，创作者可手动安全提取，提升资金安全性。

验证者证言系统

验证者可提交链上签名证言，增强事件可信度与社区背书。

Not Proof of Asset, Only Proof of Event
What Happens, Exists; What's Proven, Trusted

STProof v6.3 is the world's first on-chain protocol for objective historical events, built for the fact layer of digital civilization. v6.3 adds manual revenue withdrawal, validator attestations, and enhanced security architecture.

📄 Whitepaper v6.3 📄 中文白皮书 Genesis NFT

Core Concepts

Focus on events themselves, build a trusted fact layer without asset binding or RWA risks

Event Only

Only certify objectively occurred events, no physical asset mapping, no RWA compliance risks.

Equal Mint

Anyone can mint Event NFT with only gas fee, no entry barriers.

Zero-Knowledge Proof

Verify event authenticity without exposing privacy or core data. OTS + IPFS dual anchoring.

Multi-Source Evidence

Cross-validation of time, location, subject, behavior and materials for traceable truth.

Manual Withdrawal

Revenues accumulated on-chain, creators withdraw manually for better security.

Validator Attestations

Validators can submit signed on-chain attestations to enhance event credibility.

v6.3 Key Upgrades
