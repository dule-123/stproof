STProof v6.5 Released

Not Proof of Asset, Only Proof of Event
What Happens, Exists; What's Proven, Trusted

STProof v6.5 focuses on core event certification, adding on-chain arbitration, cross-chain validation, revenue sharing system, optimizing contract efficiency for a more complete Fact Metaverse infrastructure.

📄 Whitepaper v6.5 📄 中文白皮书 Genesis NFT

Core Concepts

Focus on events themselves, build a trusted fact layer without asset binding or RWA risks, v6.5 enhances decentralized certification capabilities

Event Only

Only certify objectively occurred events, no physical asset mapping, no RWA compliance risks.

Equal Mint

Anyone can mint Event NFT with only gas fee, no entry barriers, v6.5 optimizes Gas cost by 30%+.

Zero-Knowledge Proof

Verify event authenticity without exposing privacy or core data. OTS + IPFS dual anchoring.

Multi-Source Evidence

Cross-validation of time, location, subject, behavior and materials, v6.5 adds on-chain arbitration node verification.

Flexible Revenue System

Support manual withdrawal, multi-dimensional revenue sharing, creators can customize distribution rules for better security.

Validator Attestations

Validators can submit signed on-chain attestations, v6.5 adds attestation weight mechanism to enhance credibility.

v6.5 Key Upgrades

Decentralized, high-efficiency, scalable next-gen event certification protocol

On-chain Arbitration

Decentralized arbitration nodes to resolve disputes and enhance certification credibility.

Cross-Chain Validation

Support EVM multi-chain deployment, cross-layer event validation for multi-chain ecosystem.

Revenue Sharing

Custom multi-role revenue sharing rules with automatic proportional distribution.

Contract Efficiency

Reconstructed core logic, 30%+ lower Gas cost, 50% higher batch operation efficiency.

Layered Storage

Hot/cold data separation, on-chain hash storage, off-chain full evidence storage for security and efficiency.

DAO Governance

New DAO governance interface, validators can vote on protocol parameter adjustments.

Enhanced Security

New MEV protection, flash loan attack prevention, comprehensive contract security reinforcement.

Data Dashboard

Event certification data visualization, creators can view certification effects and revenue data.

Event Types

v6.5 supports more certification scenarios, covering physical/digital/hybrid events

Tangible Events

Mail, art creation, excavation, etc. — physical world anchored events, v6.5 optimizes physical traceability.

Intangible Events

Online publishing, voting, academic releases, etc. — support batch certification operations.

Hybrid Events

News, performances, legal deposits, etc. — new arbitration certification support.
